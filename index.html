KYRO Privacy & Policy

Local account

Username और password इस browser/device के local storage में account record के रूप में रखे जाते हैं। Password plain text में नहीं, SHA-256 hash के रूप में रखा जाता है। Browser/site data हटाने पर यह local account भी हट जाएगा।

Login

उसी username और सही password से login करने पर KYRO app खुलेगा। गलत credentials होने पर ही error दिखाई जाएगी। Create Account में password और confirm password समान होना जरूरी है।

Google login

Google sign-in Firebase Authentication के माध्यम से चलता है। Google account की authentication Firebase संभालता है।

App data

इस build में local/demo state browser/device पर रखी जा सकती है। Production deployment में अपनी final privacy policy और Firebase security rules को source of truth रखें।

About KYRO

KYRO is a mobile-first AI chat interface designed around a compact, ChatGPT-style conversation experience. The current build includes local Demo Mode plus KYRO model entries, profile controls, attachments, voice input, themes, model switching, Web Search controls, and Help & Support.

Demo ModeOffline · no key needed
Models
  • KYRO — local demo responses; no API key required.
  • KYRO 1 — KYRO model entry described as fast, vision and docs.
  • KYRO 1.2 — KYRO model entry described as reasoning and vision.
Main features
  • Chat messages with compact controls and local conversation state.
  • Photo/file attachments and a library for attached items.
  • Voice input and optional read-aloud replies.
  • Profile photo update from the profile controls.
  • Theme selection, including Pure Black mode.
  • Model switching from the compact model popup.
  • Web Search can be enabled or disabled from Settings.
  • Settings include language, API Manager, Model Manager, Voice, Web Search, backup/restore and security controls.
  • Sidebar can be opened from the menu button and by the edge swipe gesture.
Logo & status

The KYRO logo is used throughout the interface. During generation/search status it can be shown as the animated status logo; when the result is complete, the status indicator is removed.

Privacy note

This build stores its demo state in the browser session/local device state. API keys and chats are handled by the app's local state in this build.

Help & Support

KYRO

How can we help?

Chat & Messages

Type in the bottom composer and send with the arrow. Your conversation stays in the chat flow. Demo Mode returns local scripted replies; connected model entries can be used when the required API is configured.

Files & Photos

Use the composer attachment controls to add photos or files. Attached items can also appear in the local Library.

Voice & Microphone

Use the microphone control for speech input. The app also has an optional read-replies-aloud setting.

Models

The compact model popup contains KYRO, KYRO 1 and KYRO 1.2. Tap the model name to open it and select a model.

Web Search

Web Search is managed from Settings and can be enabled or disabled there.

Themes

The app supports multiple visual themes. Pure Black is designed as the minimal black-and-white presentation with animations disabled.

Profile

Open the profile control to update the profile photo. The selected photo is stored locally for the session/device state.

Settings

Settings contains language controls, API Manager, Model Manager, Voice, Web Search, backup/restore and security controls. The app also exposes About and Help & Support from the sidebar.

Sidebar & gestures

Tap the menu button to open the sidebar. The interface also supports an edge swipe gesture to open or close the sidebar.
